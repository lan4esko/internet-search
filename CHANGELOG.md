# Изменения

## Подготовка переносимой версии

- Профили Fortinet SSL VPN и Palo Alto GlobalProtect с признаками начальных GET-ответов.
- Незаданные необязательные флаги не передаются Masscan/httpx; нулевые значения сохраняются.
- Неудачные HTTP-проверки сохраняются отдельно, полнота вывода проверяется до завершения задания.
- Панель показывает причины ошибок, счётчики проверок, ответов и совпадений.
- Добавлены запуск согласованного CIDR-файла, TXT-экспорт и локальный диагностический стенд.
- Добавлены bootstrap, резервное копирование, документация переноса и проверки GitHub Actions.
- Добавлены строки команд Masscan/httpx, форматы JSON/list/XML и реальная проба на N CIDR.
- Панель показывает поток статуса Masscan и нагрузку контейнеров, обновляет данные без полной перерисовки таблиц.
- Добавлены миграция диагностики, изолированный сбор Docker stats и техническая документация архитектуры.

Результаты лабораторных проверок не считаются обнаруженными внешними системами.
