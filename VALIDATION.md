# Проверка восстановленной Internet Search v2.0

Дата: 24 октября 2026 года. Проверена восстановленная сборка из этой рабочей
среды. Результаты прежней, недоступной среды сюда не перенесены.

## Выполненные проверки

| Проверка | Результат |
| --- | --- |
| Сборка пяти основных Docker-образов | Успешно; установлены настоящие ZMap 2.1.1 и ZGrab2 v0.2.0 |
| Bootstrap, миграции и запуск семи основных сервисов | Успешно |
| Совместный прогон unit, локальной интеграции и браузерных проверок | 49 тестов, все пройдены, без пропусков |
| Проверки backup: checksum, повреждение, tar traversal, изоляция проекта | 4 теста, все пройдены |
| Регрессии архивного обработчика HTTPX | 5 тестов, все пройдены |
| Регрессии архивного интерфейса в Chromium | 7 тестов, все пройдены |
| Python compileall, проверка синтаксиса v2.js, git diff --check | Успешно |

Всего пройдено **65 различных тестов**. Отдельный предварительный прогон
41 unit-теста входит в совместный набор и повторно не учитывается.
Проверки backup добавлены в `scripts/test_v2.py` после совместного прогона:
теперь команда с `--restart-test --browser` включает 53 теста, а архивные
регрессии запускаются отдельно.

Интеграция проверена на локальном Docker fixture: реальное обнаружение ZMap,
TLS/HTTP через ZGrab2, SNI, независимое HTTP-подтверждение, запрет redirects,
SSE, snapshot-экспорт с SHA-256 и watermark, отмена задачи, восстановление
после перезапуска worker без дублирования наблюдений. В браузере проверены
создание задачи, результат, экспорт, мобильная ширина и scope dry-run.
Временное разрешение точного адреса fixture удалено после тестов.

Offline benchmark для `11.0.0.0/12`: 1 048 576 адресов представлены одним
CIDR; компиляция заняла около 0,002 с, пиковая измеренная память — 12 738 байт.
Сетевых попыток не выполнялось. Это измерение ScopeCompiler, а не скорости
сканирования сети.

Для сборки внутри облачной среды применялись локальные настройки доступа
к зависимостям и доверенного CA. Эти настройки, сертификаты и содержимое
`.env` не входят в исходники или ZIP.

## Границы проверки

- Полный цикл backup → восстановление в новый работающий стек в этой среде
  не повторялся; проверены валидация архива и изоляция конфигурации.
- Дополнительный стек Prometheus/Grafana/cAdvisor и семь dashboards
  восстановлены в исходниках, но их совместный запуск здесь не повторялся.
- Не проводились внешние массовые сканирования, проверка всех корпоративных
  прокси и независимый аудит сетевого трафика.
- Криптографический dataset GlobalProtect оставлен пустым до независимой
  калибровки; совпадение криптографического признака не означает HTTP-подтверждение.

Команды запуска и повторной проверки находятся в [README](README.md).
