# Fortinet fingerprint

Единственный рабочий профиль текущей версии перенесён из
`/home/kali/turbo/debug_scan_2.0_.sh`.

HTTPX выполняет `GET` по трём путям:

```text
/remote/login
/remote/index
/ssl-vpn/login.html
```

Совпадение ищется по ответу (заголовки и тело) по строкам:

```text
ftnt-fortinet-grid
name="magic"
SVPNCOOKIE
```

Используются пять секунд таймаута, переходы по редиректам и 500 потоков
внутри процесса. Схемы (`http`, `https`) задаются при создании TASK и входные
строки формируются явно как `scheme://IP:PORT`; fallback-схемы отключены.

Результат считается подтверждённым только после реального HTTP-ответа и
совпадения хотя бы одной настроенной строки. `200 OK`, название сервера или
открытый TCP-порт сами по себе не являются fingerprint. Запись хранится в
`httpx_results` с телом, заголовками и `match_details`, а экспорт отдаёт
`protocol://ip:port`.

Профиль Palo Alto и другие отпечатки не выполняются текущим worker и должны
добавляться отдельным согласованным шаблоном после тестового образца.
