# Панель TASK

Панель создаёт TASK загрузкой одного CIDR-файла и показывает четыре этапа:
развёрнутые IP, Masscan, HTTPX и подтверждённые Fortinet-результаты.

В деталях доступны таблицы IP, открытых `IP:PORT`, fingerprint-результатов и
экспорт TXT. Обновление запрашивает реальный статус API; результат не считается
завершённым по факту постановки в очередь.

Операции и API описаны в [task-operations.md](task-operations.md).
