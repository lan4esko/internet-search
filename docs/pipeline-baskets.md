# Чанки конвейера

В новом TASK-конвейере две независимые корзины:

1. IP-чанки Masscan размером `masscan_chunk_size`.
2. IP:PORT-чанки HTTPX размером `httpx_chunk_size`.

Закрытые порты в HTTPX-корзину не попадают. Источник и результат каждого чанка
сохраняются в физической базе TASK и raw-каталоге.
