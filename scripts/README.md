# Скрипты эксплуатации

Основной путь развёртывания — `python3 scripts/bootstrap.py`. Он создаёт
приватный `.env`, применяет миграции control database и запускает Compose.

Рабочий конвейер создаётся через API `POST /tasks` или веб-панель. Старые
скрипты snapshot/shard-контроллера больше не являются частью запуска TASK.
