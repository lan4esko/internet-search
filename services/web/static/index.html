02 / MASSCAN

Параметры Masscan

Изменения попадут в argv TASK. Ввод безопасный: shell не используется.

Поля конвейераФайл целей, формат результата и вывод назначаются worker-ом автоматически.
Управляется TASK--includefile, --output-filename, --wait 5 и --retries 0 задаются конвейером, чтобы ip(1) не терялись между чанками.
—

03 / HTTPX

Параметры HTTPX

Используется ProjectDiscovery HTTPX внутри task-runner. Это не Python-пакет httpx с хостовой ОС.

Fingerprint задаёт путь и маркерыКоманда строится только из выбранного fingerprint. Управляемые -path и -match-string нельзя дублировать в «Прочих аргументах».
Управляется TASK-list, -output, -json, -silent, -no-color, -disable-update-check, -no-fallback-scheme, -path и -match-string строятся автоматически.
